# Krishna Varshith R — Portfolio

Personal portfolio focused on regulatory technology, workflow automation,
business analysis, document and data quality, and responsible AI.

**Live site:** [gopalakrishnavarshith.github.io](https://gopalakrishnavarshith.github.io/)

## Run locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validate

```bash
npm run build
npm run lint
```

## Deployment

Pushes to `main` build a static Next.js export and deploy it through GitHub
Actions to GitHub Pages.
